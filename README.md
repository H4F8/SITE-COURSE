# 📰 SITE-COURSE — новостной агрегатор с AI-аналитикой

Сервис собирает новости из RSS-лент, анализирует тональность текстов с помощью нейросети и отдает данные через REST API.  
Фронтенд на React отображает ленту с цветовой индикацией настроения публикаций.
